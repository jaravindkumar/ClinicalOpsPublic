# v4.5 — Unified Command Centre

Presentation/integration release built on the validated v4.4 recruitment-velocity engine.

## Changes
- Portfolio headline now reports simulated enrolment from the recruitment model rather than only manually enrolled demo patients.
- Command Centre exposes actual vs expected recruitment, cumulative attainment, recent velocity, planned velocity, operational status and active risk.
- Site intelligence panel explains why a site is at risk.
- Selected-site recruitment trajectory visualises actual vs expected cumulative recruitment.
- Intervention state is explicit: same-week intervention is labelled as awaiting outcome; later weeks can show recovery.
- Existing patient, appointment, MedGemma/clinician and audit workflows remain intact.

## Frozen logic
No v4.4 alert thresholds or detection rules were changed in this release.
