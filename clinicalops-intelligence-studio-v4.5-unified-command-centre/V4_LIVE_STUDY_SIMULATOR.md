# v4.0 — Live Study Simulator

Interactive golden journey:
candidate → appointment booking → attendance/DNA → bounded evidence review → clinician decision → enrolment → follow-up → advance study clock → operational alert → intervention → recovery.

Run:
`streamlit run app.py`

Open **Live Study Simulator** from the app navigation.

Automated smoke/golden-journey test:
`python scripts/run_gate8_golden_journey.py`

The simulator uses synthetic demo patients. It is a portfolio/research prototype, not a clinical device and not prospective NHS validation.
