# Product Insights from Extractor Comparison

v0.5 turns the app from a technical demo into a product case study.

The core insight is that healthcare AI extraction quality must be measured before it is trusted inside workflow automation.

If the model performs well on open-loop detection but poorly on priority matching, the correct product response is not to abandon the model. The correct response is to constrain the model's role:

- MedGemma extracts and structures.
- Deterministic rules detect workflow risk.
- Clinicians make or confirm decisions.
- Audit logs capture overrides and failure modes.

This demonstrates AI product judgement: clear model boundary, measurable evaluation, failure-mode analysis, human-in-the-loop safety design, and workflow value beyond a chatbot.
